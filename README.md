# 클래식 하루 (CLASSIC DAY) — B2-1 팀 미션

> **상태: 완료 (보고서 제출용 문서 저장소)**
> 코드는 없고, 미션 보고서와 요건 검증 문서만 있습니다. UI 이미지 파일은 이 저장소에 올라와 있지 않습니다.
